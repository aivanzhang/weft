## Public API and concrete authoring example

```python
from weft.source_surface_anchors import reconstruct_source_surface_anchors

result = reconstruct_source_surface_anchors(
    {observation_sha256: observation_json_bytes},
    source_sha256=original_video_sha256,
    camera_document=camera_json_bytes,        # Existing supplied-camera schema.
    surface_document=surface_json_bytes,
    annotation_document=annotation_json_bytes,
)
```

All document arguments are **exact bytes**, not paths or mutable dictionaries. The function performs no filesystem/network/native-physics I/O. Run it in a trusted CLI or bounded worker, never on a UI/event-loop thread. Camera/surface/annotation arguments may be `None`; returned source rows then explain what is missing. It does not guess an unknown scale or camera. Use original-source canonical observation documents; derivative aliases require a separate verified adapter, not a copied source hash.

The following creates the two small additional documents for an existing **640×480** source with a construction observation named `person` at frame zero. The sample pixel `[320,400]` and floor height `0` are **illustrative authored inputs**, not labels for Interval or any other saved video. Replace them with explicitly selected source annotations and supplied geometry before use. `camera.json` must already match the complete source; its existing schema is documented in [camera-aware-body.md](../camera-aware-body.md).

```python
from hashlib import sha256
import json
from pathlib import Path
from weft.source_surface_anchors import reconstruct_source_surface_anchors

observations_raw = Path("scene-observations.json").read_bytes()
camera_raw = Path("camera.json").read_bytes()
observations = json.loads(observations_raw)
source = observations["source"]["sha256"]
document_sha = sha256(observations_raw).hexdigest()
row = next(r for r in observations["observations"]
           if r["object_id"] == "person" and r["frame"] == 0)
assert row["partition"] == "construction"

surfaces = {
    "schema_version": 1, "profile": "source-horizontal-surfaces-v1",
    "source_sha256": source, "calibration_sha256": sha256(camera_raw).hexdigest(),
    "world_frame": {"id": "supplied-room", "length_unit": "m", "axes": "x_right_y_away_z_up"},
    "calibration_evidence_refs": [],
    "surfaces": [{"id": "floor", "kind": "ground", "height_m": 0.0,
                  "bounds_xy_m": None, "quality": "authored",
                  "provenance": "Explicit illustrative floor hypothesis, not a measurement",
                  "evidence_refs": []}],
}
annotations = {
    "schema_version": 1, "profile": "source-surface-annotations-v1",
    "source_sha256": source, "quality": "authored",
    "provenance": "Explicit authored pixel/surface hypothesis; no contact-force evidence",
    "channels": [{"id": "left_toe", "entity_ref": {"document_sha256": document_sha, "object_id": "person"},
                  "point_role": "left toe surface-point hypothesis", "surface_id": "floor"}],
    "annotations": [{"id": f"{source}:frame:0:surface-anchor:left_toe",
                     "channel_id": "left_toe", "frame": 0, "time_s": row["time_s"],
                     "observation_id": row["id"], "status": "annotated",
                     "pixel": [320.0, 400.0], "uncertainty_px": 2.0}],
}
result = reconstruct_source_surface_anchors(
    {document_sha: observations_raw}, source_sha256=source,
    camera_document=camera_raw,
    surface_document=json.dumps(surfaces).encode(),
    annotation_document=json.dumps(annotations).encode(),
)
with Path("surface-anchors.json").open("x") as output:
    json.dump(result, output, indent=2, allow_nan=False)
```

A static support uses `kind: "static_support"`, its explicit horizontal top height, and finite `bounds_xy_m: [xmin,ymin,xmax,ymax]`. Only ground may have unbounded XY extents. A moving/handheld support is rejected. An unknown height is `height_m: null, quality: "unknown"`; it never defaults to zero. Annotation states are `annotated`, `occluded`, or `unknown`; unprovided source frames remain missing. Every channel resolves an exact document-qualified entity and same-frame observation ID/time.

For declared `measured` calibration, `calibration_evidence_refs` must resolve a construction-authorized, observed record of kind `camera_calibration_measurement`. Its original payload must bind `source_sha256`, the exact `calibration_sha256`, `units: "m"`, and nonempty `method` / `uncertainty`. A measured surface similarly requires an observed `surface_height_measurement` record in its `evidence_refs`, with the same bindings plus matching `surface_id`, `world_frame_id` and `height_m`. References use `{document_sha256, evidence_id}`. Unrelated, absent or excluded receipts cannot qualify a measured label. This checks supplied custody/binding, **not measurement authenticity or physical accuracy**; original camera/surface quality remains a claim.
