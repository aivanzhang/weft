## Geometry argument and remaining uncertainty

For binary raster width W, height H, the source mapping places each foreground
cell at `[x0+i*(x1-x0)/W, x0+(i+1)*(x1-x0)/W)` times its analogous y interval.
Contiguous foreground cells on a row have exactly the same union as one such
half-open row run; holes and disconnected rows are not filled. Inputs are exact
binary64 rationals, and cell division/intersection/distance use `Fraction`.

For a closed wrist interval `[a,b]` and half-open cell `[l,r)`, intersection is
exactly `b >= l and a < r` in each axis. The squared Euclidean distance infimum is
`max(l-b,a-r,0)^2 + max(t-d,c-u,0)^2` for rectangle y bounds`[c,d]` and cell y
bounds`[t,u)`, minimized across runs. The rational numerator/denominator is
retained; its float interval rounds outward. Infimum0 at a right/bottom excluded
boundary need not be attained, so it is not relabeled intersection. An empty
model mask remains unknown, not a physical absence claim. A declared wrist
range outside the original image abstains rather than clipping it.

Any result is conditional on the explicitly authored pixel range and the saved
model silhouette. Confidence is retained separately and does not calibrate that
range. Segmentation error, foreground occlusion, model identity ambiguity, wrist
versus hand geometry, projective depth ambiguity and calibration uncertainty
remain. Intersection/exclusion cannot establish physical contact/noncontact,
grasp, support, force or load. No shape, floor, body, scorer or task is altered.
