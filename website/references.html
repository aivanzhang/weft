01 / Seeing the scene

Seeing the scene

Models and tools used to turn video into observations.

  1. Google · Pose estimation / Implementation dependency

    MediaPipe Pose Landmarker

    Estimates body landmarks from images and video. Weft uses these estimates as inputs to its exercise reconstruction, retaining confidence and missing observations.

    Documentation ↗BlazePose paper · Bazarevsky et al., 2020 ↗

  2. Meta · Segmentation & tracking / Model integration

    Segment Anything Model 3.1

    Detects, segments and tracks objects in video. Weft’s Meta adapter uses tracking evidence to support object reconstruction; masks are not measurements of physical properties.

    Model & documentation ↗

  3. Meta · Multimodal reasoning / Model integration

    Muse Spark

    Weft uses Muse for evidence review and bounded proposals. Independent evaluation decides whether a proposed change is accepted.

    Model & documentation ↗
02 / Making it executable

Making it executable

The software foundations for simulation and reinforcement learning.

  1. Physics simulation / Implementation dependency

    MuJoCo

    The physics engine behind Weft’s articulated worlds and supported rigid-body scenes. A simulated result still depends on the scene’s geometry, contact and control assumptions.

    Project & documentation ↗

  2. Farama Foundation · Reinforcement learning / Implementation dependency

    Gymnasium

    A standard interface for actions, observations, rewards and episode boundaries. Weft uses it to expose supported simulation tasks to learning and evaluation code.

03 / Related research

Related research

Useful context for the questions Weft explores—not implementations or reproduced results.

  1. Bruce et al. · 2024 / Related paper

    Genie: Generative Interactive Environments

    Learns action-controllable environments from unlabelled video. It connects to Weft’s video-to-interaction goal; Weft instead constructs explicit, inspectable simulations for supported scenes.

    Read paper ↗

  2. Hafner et al. · 2023 preprint / Related paper

    Mastering Diverse Domains through World Models

    Introduces DreamerV3, which learns behavior by imagining trajectories in a learned world model. It provides context for learning through models; Weft does not implement DreamerV3.

    Read paper ↗

  3. Ma et al. · 2023 preprint / Related paper

    Eureka: Human-Level Reward Design via Coding Large Language Models

    Uses language models and iterative feedback to generate reward code. It relates to proposal-and-test loops; Weft keeps its independent scorer and task-success criteria outside the repair agent’s control.

    Read paper ↗

A reference is not a result.

Tools used in Weft and related research are labeled separately. Citing a paper does not mean we reproduce its method or results. Weft’s own claims depend on its recorded evidence and independent tests.
