# Portable fur diagnostics evidence

This compact, byte-preserving bundle retains seven completed diagnostic folders, including both failures. It does not contain a new avatar, render, quality approval, automatic fur promotion, or production color-policy change.

- The representation review is a proposal based on previously generated assets.
- Visibility v1 failed before projection; v2 measures two actual-model rest views using CPU projection, not renderer output. Later findings are separately hash-bound to the execution manifest.
- Color v1 exceeded its 512 MiB memory cap. V2 measured a known PNG and 12 actual JPEG texels under the same cap; its interpretation is limited to sampled byte-sRGB images.
- Edge-fringe output is an analytic curved-patch fixture, not a generated character or an accepted portable coat.

`manifest.json` maps each original project-relative path to a content-deduplicated payload. Every payload preserves exact bytes. `integrity.json` records source inventories, receipt bindings, actual run metrics, omitted inputs and verification limits. Exact commands and frozen scripts are retained inside their original receipts. Files are evidence, not a launcher: reconstruct original paths and obtain omitted inputs before reproducing any run. Do not execute saved scripts merely to inspect this bundle.

The 8,958,941-byte source JPEG is omitted at both preserved original locations because it exceeds the entire 8 MiB bundle cap. The original model and other external review inputs remain path/hash references; no model, Blend, rendered image, or source texture is replaced. Small analytic arrays and the analytic atlas are retained. This is not a complete recreation of omitted assets or the original tool installation.
