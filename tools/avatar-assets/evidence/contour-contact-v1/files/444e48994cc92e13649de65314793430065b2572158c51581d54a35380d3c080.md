Neither normals nor desired weights selected the match. No current smoothing is active. This rules out the latest fringe geometry as the origin of the base contact shape or color.

Material names alone are misleading. `body_cap` comprises 245 authored closure triangles **and 124 original triangles whose UVs were repainted**. `companion_cap` comprises 228 closures and 85 repainted originals. A cap-material operation therefore also touches original visible surface normals. The current body undercoat splits these into primitives 2 and 6; original body surfaces occupy primitives 0, 4 and 5.

The prepared source contained 62,614 triangles. Thirty-three expected triangles are absent in both v7's exported GLB and the current GLB; IDs are retained in `provenance.json`. This inspection does not establish why the old exporter omitted them. The old native topology/intersection report describes pre-export arrays, not independent validation of the exported mesh.

## Smallest reusable repair direction

1. Review the confined source-normal control first. If it helps, distinguish authored closures from UV-repainted originals in repair metadata. Never choose all cap-named material faces as if all were newly authored geometry. A reusable normal operation should protect original normals and reject unsupported cross-fan/hemisphere transfers rather than silently flipping them.
2. Repair shoulder color separately with explicit material/part, bounded hidden-contact region and protected-surface selectors. Prefer a bounded authored UV/palette correction whose source sampling also feeds native/portable fur. A constant material that excludes the shoulder from fur would recreate a bald region. Preserve source image bytes and record changed face IDs/UV hashes. Validate a low-variance palette neighborhood and its filtering footprint, not only a 28-pixel tile mean.
3. Only if the actual normal control leaves a visible shape defect, consider replacing the disclosed hidden contact patch using a bounded healthy outer-ring fit and constrained curved patch. Preserve the outer boundary, explicit displacement/triangle bounds, skin transfer and intersection diagnostics. This differs from repeating flat/minimum-area caps, but is still an authored assumption and requires a new review. No geometry repair is implemented here.
