# Independent fringe fidelity diagnostic

The frozen producer can restore only the selected experimental fringe's normal,
joint and weight payloads. The independent audit imports no producer code. It
compares every other file byte, exact authored helper payloads, actual unchanged
body-root weights and nine exported-skin poses per clip. Fox additionally compares
the original GLB body to the native-export body at its original 1e-5 m pose gate.

These are CPU diagnostics of retained exports, not successful full native finishes.
The panda runs failed their native memory limit. Existing fox body-normal failures
and ambiguities remain. A restored helper value is not proof of body attachment,
native evaluated motion, appearance, continuous motion, physical hair or Muse parity.

- Producer: one attempt per case; 30 s, 512 MiB, 128 MiB output; no native or provider calls.
- Independent audit: 50 s internal deadline; caller 60 s, 512 MiB, 32 MiB output.
- Original gates: normals 0.0002, weights/root gap 1e-6; fox pose 1e-5 m.
- Panda's new 1e-6 m helper-pose gate is separate from any historic native comparator.
- `thresholds.json` has a literal hash in `audit.py`; the repair request cannot substitute looser gates.
- `oracles.py` checks STEP timing, quaternion interpolation, hierarchy and skin math using known analytic answers.

All failures are preserved. No defaults, public finishing guards or avatar outputs
are promoted by this study. `prepared.json` pins the exact producer and checker
sources before either actual derivative is generated.
