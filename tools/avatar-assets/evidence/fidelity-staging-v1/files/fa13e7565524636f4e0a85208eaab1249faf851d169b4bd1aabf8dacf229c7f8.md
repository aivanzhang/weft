# Fringe exporter cause investigation

**Weights: proven exporter pruning. Normals: legacy storage snapping explains the six extreme actual witnesses. No assets accepted or changed.**

## Installed Python path

- `primitive_extract.py:1539,1553–1554` drops weights **≤0.0001** before influence-count options. `primitive_attributes.py:149–161` normalizes the remaining float32 rows. Replaying this installed method on the three worst saved panda rows reproduces the exported weights **bit-for-bit**. “All influences” does not bypass the earlier pruning.
- `primitive_extract.py:1435–1442` reads `mesh.corner_normals`, rounds to four decimals, then normalizes. Applying that rounding alone to all intended helper normals changes components by at most **5.77e-5 panda / 6.18e-5 fox**; none crosses the existing 0.0002 gate.

## Native storage path and scope

The producer calls the legacy vertex-normal setter. The version-matched [RNA source](https://github.com/blender/blender/blob/v4.5.13/source/blender/makesrna/intern/rna_mesh_api.cc#L132-L149) forwards to custom-normal storage. [The kernel](https://github.com/blender/blender/blob/v4.5.13/source/blender/blenkernel/intern/mesh_normals.cc#L1474-L1527) stores that path in two short integers per corner. Its [near-axis branch](https://github.com/blender/blender/blob/v4.5.13/source/blender/blenkernel/intern/mesh_normals.cc#L697-L739) snaps beta to zero at cosine ≥0.999899983.

All six worst actual panda/fox corners meet that condition. The isolated snapping formula predicts their exported normals within **6.93e-5**, compared with the original **~0.0136** component errors. This is strong cause localization using exact saved geometry, not a full native-internal replay or attribution of every smaller error. The same source supports direct float-vector custom normals; that alternative still needs a small native test.

## Safest bounded correction

Keep raw exports. A separate, disabled-by-default derivative can restore only the fringe’s intended normals and all ≤4 positive joint weights from hash-pinned helper arrays after unique position/UV matching, exact oriented-triangle coverage, and explicit exported bone-name mapping. Append new accessors; do not rewrite body attributes, original binary bytes, textures, UVs, rig or animation. Reject ambiguity or unknown transforms. Keep the existing normal/weight gates and independently check weighted poses. Do not perturb the geometry, inflate tiny weights, or patch the installed exporter to hide this loss.

A float-vector native normal attribute is a separate producer hypothesis; a portable-only restoration does not silently fix the editable Blend’s legacy normals. Neither correction establishes fur quality.
