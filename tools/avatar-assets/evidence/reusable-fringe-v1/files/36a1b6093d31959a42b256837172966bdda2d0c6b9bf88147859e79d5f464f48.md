## Output budget

The preparation uses an empirical editable-Blender-file estimate: 1.25× the named previous file, plus 1.5× positive final-model growth. It adds a conservative raw-scanline PNG allowance and 18 MiB for logs/metadata. This is not a rigorous bound on unknown Blender compression.

If final models equaled the reference sizes, estimated totals would be 123,041,461 bytes for panda and 128,518,853 bytes for fox, below the 134,217,728-byte cap. Fox has only 5,698,875 bytes of provisional headroom. The actual final source size must be checked. An estimate above the cap is rejected; runtime monitoring enforces the same cap. No bound increase or automatic retry is prepared.
