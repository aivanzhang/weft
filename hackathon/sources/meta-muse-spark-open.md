## Meet Muse Spark Open

Enhanced coding capabilities

Muse Spark Open writes, reviews and ships code with fewer steps and lower latency. Whether you're building coding agents or using AI as a development partner, it's competitive with the best.

Native multimodal perception

Muse Spark Open perceives video, images, and documents, and its visual reasoning runs through a real execution environment instead of scripted steps. Feed it a screenshot or a clip and let it build, so you can focus on shipping features fast.

End-to-end agentic workflows

Build and orchestrate multi-agent workflows with one model. Move from idea to feature quickly and spend time testing, learning, and building instead of configuring. A separate commentary channel lets the model state intent before acting – so you always know what it's doing and why.

Muse Spark

### Introducing Muse Spark Open

Muse Spark Open is derived from the Muse Spark model we released in August, with additional safety post-training to make it more robust against misuse as a standalone model without system guardrails.

[Read more](http://dev.meta.ai/resources/blog/build-with-muse-spark-open)
