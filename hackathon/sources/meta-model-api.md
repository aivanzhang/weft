# Meta Model API

Direct, self-serve and affordable access to Muse models. Start building your agentic and multi-modal workflows in minutes.

## Start building with Meta Model API

Web search grounding

Connect your agents to real, current information with web search grounding, available through the Meta Model API. Turn it on when accuracy matters.

Familiar developer experience

Meta Model API makes it easy to get started: generate a one-click API key, point your existing OpenAI SDK code at it and you're up and running.
